# Fichiers météo

Déposez ici les fichiers EPW, un par ville, sous le nom indiqué dans `std_maroc/donnees/climats.json`
(`agadir.epw`, `errachidia.epw`, etc.).

Ils peuvent être téléchargés automatiquement depuis [climate.onebuilding.org](https://climate.onebuilding.org/WMO_Region_1_Africa/MAR_Morocco/) :

```
python -m std_maroc meteo agadir errachidia
```

Les fichiers EPW ne sont pas versionnés.
